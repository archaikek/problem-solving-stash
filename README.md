# problem-solving-stash
Repository for codes for competitive programming problem solving and similar.

Different branches contain solutions for different problems, which will be linked in their respective readmes. 

## tpikies-gold-mine
Solution for the problem tpikies_GOLD_MINE from https://stos.eti.pg.gda.pl/index.php?p=show&pid=1551&cid=712. The contest will most likely be unavailable to outsiders.

### Solution
Use dynamic programming over rows (exact), columns (exact) and walls broken through up to this points (strictly less than). Each cell should contain three seperate results for achieving it by coming from 3 different directions.
